# Changelog

## Version 2.0 — Current

- Added prismatic and pouch configuration alongside cylindrical cells.
- Expanded cooling to top, bottom, top + bottom, side, serpentine and forced air.
- Added configurable ohmic, 1RC and 2RC electro-thermal representations.
- Added automated cooling-operation and architecture-specific design sweeps.
- Added shared design limits, independent adjustable cooling/design ranking priorities, all-case plots and CSV/MAT exports.
- Included Fan 2019 forced-air and Bahiraei 2017 bottom-cooling literature-comparison workflows.
- Retained thermal KPIs and height-distributed 3D nodal visualization.

### Repository packaging update

- Added the required project-local `Thermal_Pack_Libraries/` sources and libraries from the supplied Version 2.0 archive.
- Updated the main README, launch instructions, verification status and version roadmap.
- Archived the Version 1.0 README and retained the Version 1.0 app/model.
- Excluded the Version 2.0 generated working model from version control.
- Confirmed that the current Version 2.0 application and master model already match the supplied archive byte-for-byte.

## Version 1.0 — Retained baseline

- Configurable cylindrical battery modules with bottom liquid cooling.
- Dynamic load profiles, thermal KPIs, hotspot identification and threshold-based safety margins.
- Battery geometry and time-resolved 3D nodal temperature visualization.

## Version 3.0 — Planned

Broader experimental/CFD validation, expanded pack-level analysis, advanced safety modelling and investigation of machine-learning-assisted acceleration. These capabilities are development goals.
